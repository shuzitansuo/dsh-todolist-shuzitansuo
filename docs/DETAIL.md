# 任务日历

一个独立的本地任务日历插件。界面和交互参考日历应用，数据只存在本机。

左侧是插件菜单，可在**任务**、**日历**、**看板**、**四象限**、**总结**和**番茄**之间切换；底部有**设置**和**检查更新**。打开后默认进入日历的**日视图**，视图顺序为日 / 周 / 月，可随时切换。

## 功能

- **周视图**：周一至周日七列，任务按截止日期落格；可隐藏周末和法定节假日。
- **月视图**：固定 6 行 42 格，每格最多显示 3 个任务，可翻月。
- **日视图**：08:00–24:00 时间轴，按任务的预计工时排块；重叠任务自动分列。拖动任务块改开始时间，拖动上下边缘改时长，数据写回本地库。
- **任务**：双击日期空白处新建；周视图内拖动任务可改截止日期，拖到同日其他任务上可排序。
- **完成与状态**：任务前的复选框直接标记完成，已完成的任务再点一次复选框会取消完成、回到未开始；右键任务可「放弃」或「删除」；完成用复选框，其他状态在详情顶部的状态标签里修改，P1 红、P2 黄、P3 蓝。已完成的任务不能放弃：右键菜单不显示「放弃」，详情状态里的「已放弃」不可选。
- **日历过滤**：已放弃的任务不会出现在日 / 周 / 月视图中，仍保留在任务清单里；已放弃后不能改回待完成/进行中/已完成，只能删除。
- **已放弃标记**：任务清单里已放弃任务前面的复选框显示为灰色禁用框、中间一个叉，不会再被误点完成；日历里的已放弃任务同样只显示灰色叉，不显示可点的复选框。
- **已放弃分组**：已放弃任务不混在日期分组里，始终单独成一组放在任务列表最下面；组内只包含当前筛选命中的已放弃任务。侧栏的今天/明天/最近 7 天/收集箱数量不计已放弃任务。
- **今天视图的已完成组**：在「今天」筛选下勾选完成任务后，任务不会立刻消失，而是移到列表底部的「已完成」组；取消勾选会回到日期组。侧栏「今天」数量仍只计未完成任务，「已完成」筛选仍按日期分组。
- **农历与节假日**：农历日期、二十四节气、传统节日，以及 2025–2027 年法定节假日和调休标记。
- **日视图详情**：显示标题、可修改的状态/优先级/分类标签和 Markdown 描述；点击正文进入编辑。

新建任务只需标题、优先级、分类、截止日期（可选开始时间和描述），不包含迭代和指派人字段。

- **任务分类**：新建任务时可选分类（默认「工作」）；快速添加默认归到当前筛选分类，否则归到第一个分类。任务详情顶部的分类标签可直接改。
- **卡片颜色**：任务列表只保留左侧 3px 分类色条，不铺色底；四象限不显示分类色条；只有周/月视图、日视图保留分类浅色底 + 色条。未分类任务使用中性灰。
- **分类筛选**：任务视图左侧「清单」下方按分类列出「全部」、各分类和「未分类」，数量随当前日期筛选更新；点击分类只看该类，再次点击或点「全部」清除。
- **分类管理**：设置页可新增、改名、改色、删除分类；名称最多 24 字、最多 30 个，颜色为十六进制。删除分类不会删除任务，任务会回到未分类。
- **默认分类**：工作（#2f7cf6）、生活（#22a06b）、学习（#7c5cff）、健康（#e37318）、娱乐（#e5457a）、放松（#0f9f8f）。

## 传统节日与数据来源

- 日历按农历标注：春节、元宵节、龙抬头、上巳节、寒食节、清明节、端午节、七夕、中元节、中秋节、重阳节、寒衣节、下元节、冬至、腊八节、小年、除夕。
- 小年分南北：腊月二十三标「小年·北」，腊月二十四标「小年·南」。清明节、冬至按节气日期标注，并优先显示为传统节日。
- 寒食节取清明前一日；同一天只显示一个农历标签，节日优先于二十四节气。闰月不标传统节日。
- 农历日期以香港天文台《公历与农历对照表》（1901–2100）为准：
  - 官方页面：https://www.hko.gov.hk/sc/gts/time/conversion.htm
  - 开放数据：https://data.gov.hk/sc-data/dataset/hk-hko-rss-gregorian-lunar-calendar-conversion-table
- 2025–2027 共 1095 天已用香港天文台 CSV 逐日对照，农历月/日 0 差异；清明、冬至日期另对照 2025–2027 年年历 PDF。注意：部分软件的中国农历实现会把 2027-02-06 标成腊月三十，香港天文台明确该日为丁未年正月初一，本项目以香港天文台表为准。
- 农历换算表覆盖 1901–2100；超出范围时只显示公历，不推测农历。

## 四象限

- 左侧「四象限」用重要 × 紧急两个维度展示所有未完成、未放弃的任务，初始按优先级和截止日期自动归类。
- **重要**：P1 / P2；**紧急**：截止日期是今天或已经逾期。P3 视为不重要。
- 四张卡片分别是重要且紧急、重要不紧急、紧急不重要、不重要不紧急，各自显示任务数；卡片内按截止日期排序，并标注优先级、日期和番茄数。
- 单击任务弹出详情窗口，可直接改状态、优先级和分类；复选框可直接完成任务。
- **双击新建**：双击某张卡片的空白处，会新建任务并直接放入该象限。默认优先级/截止日期为：重要且紧急 P1/今天、重要不紧急 P2/明天、紧急不重要 P3/今天、不重要不紧急 P3/明天；创建后仍带「手动」标记，之后改优先级或日期也不会换象限。
- **拖动改象限**：把任务拖到其他卡片，只会记录它属于哪个象限，**不改优先级，也不改截止日期**。已手动拖过的任务会带一个「手动」标记，之后修改优先级或日期也不会自动换象限。
- 没有手动拖过的任务仍按优先级/截止日期自动归类；拖动失败会恢复原数据。手动象限保存在本地 SQLite 的 `tasks.quadrant` 字段，换浏览器或刷新页面都不会丢。

## 看板

- 三列：未开始 / 进行中 / 已完成；已放弃任务不显示，列头显示该列任务数。
- 拖动卡片到另一列即可改状态，只改状态，不改优先级和截止日期；拖回原列不会发请求。
- 卡片可直接勾选完成，再点一次取消完成；点击卡片打开详情弹窗，键盘 Enter / Space 也可打开。
- 卡片刻度：优先级、分类色点与名称、截止日期与时间（过期红色）、番茄数；排序为优先级、截止日期、开始时间。
- 右上角「新建任务」复用任务弹窗；窄屏下三列横向滚动，不挤压页面。

## 任务清单

- 左侧二级菜单按**今天 / 明天 / 最近 7 天 / 收集箱 / 已完成**筛选，并显示数量。
- 列表按截止日期分组；顶部输入框回车即可快速新建任务，默认截止到当前筛选对应的日期。
- **分组折叠**：点击分组标题可折叠或展开该组，也可以聚焦标题后按空格/回车；折叠状态会记住，只影响显示，不影响任务数量和筛选。
- **滚动条**：平时透明，滚动时出现；停止滚动约 0.9 秒后自动隐藏，不改变内容宽度。
- **拖拽排序**：同一日期分组内可拖动任务调整顺序；顺序与日历视图中的任务顺序同步并会记住，不会改变截止日期。
- **标题日期识别**：标题里的日期会自动识别并从标题中移除——今天/明天/后天/大后天/昨天、周三/下周三/本周五、11月30日/十一月三十号、2026-12-05、3天后等。无论当前在哪个筛选，都按识别出的日期创建。例如「明天给花浇水」会创建标题「给花浇水」、截止明天的任务。
- **标题时间识别**：标题里的时间也会自动识别并从标题中移除——上午9点、下午3点半、晚上8点15分、9:30、九点一刻等；任务按识别出的时间创建，默认时长 30 分钟；列表显示日期和时间，日视图按时间显示半小时块。只写时间不写日期时，按当前筛选的日期创建（收集箱按今天）。例如「明天上午9点开会」会创建标题「开会」、截止明天 09:00、时长 30 分钟的任务。
- 单击任务在右侧查看详情：标题、状态/优先级标签和 Markdown 描述；顶部标签可点击修改，不显示日期、工时和删除按钮。
- **Markdown 描述**：详情中的描述直接渲染 Markdown（标题、加粗/斜体、列表、待办、引用、代码块、链接等）；点击正文进入编辑，编辑框占满详情剩余高度。输入后约 0.3 秒自动保存；点击编辑框外、切换任务或按 Esc 会收起并立即落库。没有保存/完成按钮，也不显示保存状态或格式提示。
- **子任务**：任务详情底部最多添加 10 个子任务，每条用 Checkbox 展示；勾选后进度条和百分比立即更新，可逐条删除；删除任务时子任务一并删除。
- 勾选复选框直接完成任务，再点一次可取消完成；右键任务可快速「放弃」或「删除」，删除前会二次确认。
- **列宽拖拽**：任务清单三栏之间的两条竖线可拖动调整宽度。任务栏 168–320px，详情栏 300–620px，中间列表自动占满剩余空间；窄屏下详情变成右侧浮层，只保留任务栏一条拖拽线。宽度会记住。
- **日视图列宽**：时间轴和右侧任务详情之间的竖线也可拖动，详情宽度限制在 240–520px，宽度会记住。
- **自适应**：页面随 DSH 窗口宽度流式铺满，周/月七列自动等分；窗口变窄时日历头部自动换行，700px 以下日历去掉外边距，日视图详情以浮层方式打开。

## 总结

- 左侧「总结」进入复盘页，顶部切换**日总结 / 周总结 / 月总结**，可用左右箭头切换周期、回到今天。
- 指标卡：任务总数、已完成、完成率（不含已放弃）、待推进与逾期数。
- 每日完成情况：按任务截止日期归属到每一天，列出完成数/应完成数、进度条和任务清单；点击任务可跳回任务清单并打开详情。周总结显示整周 7 天，月总结只列出有任务的日期。
- **48 格时间带**：每一天用 48 个小格表示 24 小时，每格半小时，格子上方标 00/06/12/18/24。按任务开始时间和预计工时填色（没有开始时间时从 09:00 起顺排），颜色取任务分类色；已完成任务半透明；没有任务的格子为灰色。同一时段有多个任务时先到先占。
- 智能复盘：按 **KISS（保持 / 改进 / 开始 / 停止）** 生成总结与建议，包含本周期亮点、逾期与低完成率提醒、下一步动作和要停止的习惯；可换一种表达重新生成，也可一键复制全文。
- 内容复盘：AI 卡片会按任务标题（必要时参考描述）自动归类（需求与产品、设计与体验、写作与汇报、数据与分析、研发与交付、沟通与协作、运营与内容、学习与成长），列出本周期主线，以及已完成 / 待推进 / 已放下的主题和具体任务；复制全文时包含同一段内容。
- 番茄专注：汇总本周期番茄数、专注时长、专注次数和涉及任务；周/月总结按天显示柱状分布，日总结显示任务专注排行。每日完成行右侧同时标注当天 🍅 数与专注时长，KISS 和复制文本会引用番茄数据。
- 我的感想：每个日 / 周 / 月周期一份自由文本，输入后自动保存，失焦或按 ⌘/Ctrl + Enter 立即保存；切换周期会加载对应内容，保存到本地 SQLite 的 `reflections` 表。
- 复盘文字由本地根据任务数据自动生成，不调用外部模型，也不上传数据。

## 番茄

- 右键任意**未完成、未放弃**任务选择「开始番茄钟」，可倒计时（25 / 30 / 45 分钟或 1–180 分钟自定义，默认 25 分钟）或正计时；已完成、已放弃任务的右键项置灰，详情里也不显示「开始专注」。
- 倒计时完成后自动记 1 个番茄，页面中央弹出庆祝框：大号点赞动效、完成任务名和专注分钟数；点「收下这个赞」、遮罩或 Esc 关闭。任务标题后显示 🍅 标记，多个番茄显示多个图标；正计时只累计专注时长，不增加番茄数。
- 任务详情顶部显示该任务的累计专注时长和番茄数，可直接点「开始专注」。
- 计时器固定在右下角，可暂停、继续、停止；停止时不足 5 秒不记录。倒计时进行中关闭页面后恢复为暂停状态，不会跨天误记番茄。
- 左侧「番茄」页按天统计：番茄数、专注时长、专注次数、涉及任务、近 7 天柱状图、当天专注记录与任务专注排行。专注记录左侧用一条竖线串起每次专注（圆点：已完成番茄为品牌色，正计时/未完成为灰色）。可切换日期、回到今天和刷新。
- 番茄记录保存在本地 SQLite 的 `pomodoro_sessions` 表；倒计时完成才算番茄，手动停止和正计时只记录时长。

## 数据位置

`$DSH_HOME/calendar/db/calendar.sqlite`，默认是 `~/.dsh/calendar/db/calendar.sqlite`。备份或换机时拷这个文件即可。数据库使用 WAL 模式，同目录下可能还有 `-wal`、`-shm` 文件。

## 交互提示

- 双击空白处：新建任务。
- 单击任务：日视图打开右侧详情。
- 右键任务：放弃、删除，或开始番茄钟。
- 四象限：单击任务弹出详情窗口，复选框完成任务。
- 拖动任务：改日期 / 排序。
- 日视图拖动块：改开始时间；拖上下边缘：改预计工时。
- 桌面端可拖拽顶部区域（日历标题栏 / 任务页标题 / 内容区最上沿）移动窗口。

## 限制

- 单机、单用户，没有登录和同步。
- 节假日数据内置到 2027 年，之后需要更新。
- 任务没有提醒和重复规则。

## 数据与迁移

- 任务、分类、番茄记录、「我的感想」和本机日历开关都保存在本机 SQLite：`$DSH_HOME/calendar/db/calendar.sqlite`（未设置 `DSH_HOME` 时为 `~/.dsh/calendar/db/calendar.sqlite`）。浏览器只负责显示，换浏览器、清缓存不会影响这些数据。
- 数据库在插件目录之外，升级或卸载插件不会删除它；插件包本身也不包含数据库文件。其他人安装后首次打开会自动创建空数据库并建表。
- 需要换电脑时，退出 DSH 后复制 `calendar.sqlite` 到新机器的同一路径即可；WAL 模式下建议退出后再复制，避免漏掉尚未合并的写入。


## 设置

- 左侧栏底部的「设置」进入设置页。设置页为左右结构：左侧是「任务分类 / 日视图 / 本机日历 / Obsidian / 数据位置」五个分区，点击后右侧显示对应详细设置。
- **任务分类**：左侧选「任务分类」，右侧管理分类，可改色、改名、删除或新增；删除分类只把任务改为未分类，不删除任务。
- **日视图时间范围**：用两个下拉选择开始和结束时间，默认 08:00–24:00，按 30 分钟步进，至少 1 小时。日视图的刻度、任务块位置、拖拽/缩放、双击新建和当前时间线都会跟随；时间范围较短时会按可用高度缩放刻度、铺满内容区。与范围有重叠的任务/日程会截到边界内显示，完全落在范围外的不显示。设置保存在本机数据库的 `settings` 表。
- **本机日历同步**：开启后读取 macOS「日历」里带具体时间的日程，按当前日 / 周 / 月视图的范围显示在日历上。日程是只读的，不会修改或删除系统日历；首次开启时 macOS 会请求日历权限。
- 全天日程不会导入，避免生日、节假日等占满格子；生日、节假日、Siri 建议、提醒事项等系统日历也会跳过。
- 日程在日历里用灰色块显示，周/月视图显示时间和标题，日视图按时间排布并与任务一起分列；任务仍然可以拖动、完成和改状态，系统日程不能拖动。
- 同步开关、上次读取时间和可用的日历名称会显示在设置页；点「重新同步」可绕过 60 秒缓存立即读取。读取失败时会在设置页和日历头部提示。
- 本地日程只用于展示，不写入插件数据库；插件只保存「是否开启同步」这个开关。

### Obsidian 日志

- 在设置页左侧选「Obsidian」，填写本机 Obsidian 仓库目录（必须是绝对路径，支持 `~/` 开头），设置写入标题（默认 `## todo`）和自动写入间隔（1–1440 分钟，默认 30 分钟）。
- 目标文件固定为「仓库目录/YYYY-MM-DD.md」；文件不存在时自动创建。只访问填写的目录，不读取其他笔记，不联网、不上传。
- 只替换「写入标题」到下一个同级或更高级标题之间的内容，标题外的原文保留；标题不存在时追加到文件末尾。
- 当天任务按截止日期筛选，未完成在前、已完成在后；有开始时间的写成 `HH:MM`；已放弃任务不写入。每次整节覆盖，不会重复累加；当天没有任务时写入 `- 今日暂无任务`。
- 同一次写入还会更新固定的 `## 今日总结` 节：当天专注分钟数、番茄数、任务完成率、逾期/放弃数量、AI 复盘（本地规则生成，不调用外部模型）和当天的「我的感想」；该节不存在时追加到文末。感想以引用块写入，避免其中的标题破坏段落边界。
- 任务写入标题不能使用「今日总结」，否则会与固定的总结节冲突，保存时会报错。
- 「保存并立即写入」会保存配置并写一次；「仅保存」不写；「立即写入」使用已保存的配置，不受自动开关影响。开启自动写入后按间隔执行（需保持 DSH 运行），关闭开关会停止自动写入。
- 写入使用临时文件 + 原子替换；同步状态（上次写入时间、结果、错误）显示在设置页。若目录不存在或无权限，会显示具体错误，不会改动文件。

## 检查更新

左侧栏底部的「检查更新」会读取 GitHub 仓库的最新 Release；仓库只打了 Tag、没有发 Release 时，读取最新 Tag。版本号与 `package.json` 的 `version` 比较，有更新时显示更新说明和 GitHub 链接。

- 第一次使用需要在弹窗里填写仓库，例如 `owner/repo` 或 `https://github.com/owner/repo`，保存在本机数据库，不会上传任何数据。
- 也可以在启动前设置 `DSH_CALENDAR_REPO=owner/repo`，或在 `package.json` 的 `repository` 字段里写仓库地址，安装后默认就有更新源。
- 这里只检查和跳转，不会自动覆盖安装；下载新版本后按插件安装流程更新即可。
- 发布新版本时先改 `package.json` 的 `version`，再打 `v0.2.0` 这样的 Tag；建议同时创建 Release 并写更新说明。
